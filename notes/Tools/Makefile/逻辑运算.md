GNU Make 并不是一门普通的命令式语言。它没有可以随处使用的 `==`、`!=`、
`&&`、`||` 运算符，而是把逻辑判断分成两套机制：

1. **条件指令**：在解析 Makefile 时决定哪些文本参与构建。
2. **函数表达式**：将空字符串视为假，将非空字符串视为真。

---

### 一、字符串相等与不等

在 Makefile 顶层进行分支时，最清晰的方式是 `ifeq` 和 `ifneq`：

```makefile
BOARD ?= 0

ifeq ($(BOARD),1)
SIM_BUILD_TAG := $(SIM_TARGET)-board
else
SIM_BUILD_TAG := $(SIM_TARGET)
endif
```

判断不等：

```makefile
ifneq ($(SIM_TARGET),npc)
CPPFLAGS += -DCONFIG_SOC
endif
```

为了避免变量值两侧的意外空格干扰判断，可以先使用 `strip`：

```makefile
ifeq ($(strip $(BOARD)),1)
...
endif
```

---

### 二、`if` 函数

`if` 函数可以嵌入变量定义：

```makefile
$(if CONDITION,THEN,ELSE)
```

它不比较真假值，只判断 `CONDITION` 展开后是否为空：

```makefile
DEBUG_SUFFIX := $(if $(DEBUG),-debug,-release)
```

这里即使 `DEBUG=0`，`0` 仍然是非空字符串，因此结果依旧是 `-debug`。若只希望
`DEBUG=1` 为真，需要先过滤：

```makefile
DEBUG_SUFFIX := $(if $(filter 1,$(DEBUG)),-debug,-release)
```

---

### 三、逻辑与、逻辑或

GNU Make 提供 `and` 与 `or` 函数：

```makefile
$(and CONDITION1,CONDITION2,...)
$(or CONDITION1,CONDITION2,...)
```

`and` 从左到右展开参数，遇到空字符串立即停止；全部为真时返回最后一个参数。
`or` 遇到第一个非空字符串立即停止，并返回它。

```makefile
ENABLE_TRACE := $(and $(filter npc,$(SIM_TARGET)),$(filter 1,$(DEBUG)))
SELECTED_CC  := $(or $(CUSTOM_CC),$(CC),cc)
```

取反没有专门的 `not` 函数，通常用 `if` 交换两个分支：

```makefile
NOT_BOARD := $(if $(filter 1,$(BOARD)),,1)
```

---

### 四、用 `filter` 判断集合成员

`filter` 本质上是模式过滤，但经常用来判断一个值是否属于集合：

```makefile
SOC_TARGETS := ysyxsoc ysyxsoc-bootloader

ifneq ($(filter $(SIM_TARGET),$(SOC_TARGETS)),)
CPPFLAGS += -DCONFIG_SOC
endif
```

一行表达式写法：

```makefile
IS_SOC := $(filter $(SIM_TARGET),$(SOC_TARGETS))
```

注意：`filter` 的模式中 `%` 有通配含义，所以它不是严格的通用字符串比较器。
对于普通配置值，例如 `0`、`1`、`npc`，使用它通常没有问题。

---

### 五、变量是否定义

```makefile
ifdef NEMU_HOME
$(info NEMU_HOME is set)
endif

ifndef NEMU_HOME
$(error NEMU_HOME is required)
endif
```

`ifdef` 判断变量是否具有非空值，而不是判断变量名是否曾经出现过：

```makefile
EMPTY :=

ifdef EMPTY
# 不会进入这里
endif
```

需要精确区分“未定义”和“已定义为空”时，可以使用 `origin`：

```makefile
ifeq ($(origin EMPTY),undefined)
$(info EMPTY was never defined)
endif
```

---

### 六、数值比较

Make 本身没有数值比较运算符。简单配置最好使用字符串比较：

```makefile
ifeq ($(OPT_LEVEL),2)
...
endif
```

真正的大小比较通常交给 Shell：

```makefile
IS_LARGE := $(shell [ "$(COUNT)" -gt 10 ] && echo 1)
```

在 recipe 中则直接使用 Shell 条件语句：

```makefile
check:
	@if [ "$(COUNT)" -gt 10 ]; then \
		echo "large"; \
	else \
		echo "small"; \
	fi
```

### 总结

| 需求 | 推荐方式 |
| :--- | :--- |
| 顶层字符串分支 | `ifeq` / `ifneq` |
| 判断变量是否非空 | `ifdef` 或 `$(if ...)` |
| 一行条件表达式 | `$(if CONDITION,THEN,ELSE)` |
| 逻辑与、逻辑或 | `$(and ...)` / `$(or ...)` |
| 判断集合成员 | `filter` |
| 判断变量来源或是否真正定义 | `origin` |
| 数值大小比较 | Shell 的 `test` / `[` |
