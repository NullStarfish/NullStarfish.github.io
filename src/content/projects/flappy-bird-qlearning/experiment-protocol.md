## 单因素参数扫描

`parameter_sweep.py` 以基线配置为中心，每次只改变一个参数。各组训练 50,000 局，用固定的 100 个测试种子执行无探索贪心策略，并输出逐局分数、汇总 CSV、训练曲线、对比图和最佳 Q-table。

| 参数 | 基线 | 扫描值 |
| --- | ---: | --- |
| 学习率 `α` | 0.5 | 0.3, 0.5, 0.7 |
| 折扣因子 `γ` | 0.90 | 0.85, 0.90, 0.95, 0.99 |
| 探索率 `ε` | 0.10 | 0.05, 0.10, 0.20 |
| 量化倍率 `m` | 30 | 10, 20, 30, 50 |
| 死亡奖励 | -1000 | -1, -100, -1000 |

本次扫描中，`γ = 0.95` 的模型获得最高测试平均分 444.12（中位数 380，标准差 330.34）。评估设置单局 `score_limit=1000`，因此触顶样本是右删失数据，不能将其最高分视为未截断表现。

## 训练检查点

主训练代码每 500 局记录一次带探索训练回合的平均分，并单独运行 20 局固定种子、关闭探索的贪心评估。评估前保存并在完成后恢复 Python 与 NumPy 的随机数状态，避免中间评估改变后续训练轨迹。

![训练中带探索分数与定期贪心评估曲线](/projects/flappy-bird-qlearning/training-curve.png)

*蓝线是关闭探索后的定期贪心评估；橙线保留 `ε = 0.1`，因此不能直接用来衡量最终策略能力。*

## 解释边界

一次扫描中的误差棒是同一模型在 100 个游戏局上的分数离散度，不是多个独立训练模型之间的方差。参数扫描用于发现候选配置；最终模型由保留的训练里程碑在另一条连续播放评估链路中复测。项目不把单次训练的最优结果解释为某组超参数的稳定期望性能。
