## 系统任务

电路模型探究装置需要完成三个连续但边界独立的功能：

| 功能 | 输入 | 输出 |
| --- | --- | --- |
| 已知模型控制 | 目标频率、目标输出 Vpp | 满足目标的 DDS 激励 |
| 未知模型学习 | 被测电路端口 | 滤波类型、`k`、`f0`、`Q` |
| 未知模型模拟 | 外部实时信号 | 与被测电路幅频特性一致的 DAC 输出 |

已知模型路径用于验证传递函数反算和闭环校正；未知模型路径完成扫频测量、参数辨识与数字滤波器生成。

## 已知模型

已知网络为二阶低通系统：

```text
                 5
H(s) = -------------------------
       1e-8 s² + 3e-4 s + 1
```

控制范围为 100 Hz–3 kHz、1–2 Vpp。给定目标 `Vout` 后，固件先计算

```text
Vin = Vout / |H(jω)|
```

再用实测输出更新输入幅值。校正完成后，频率和目标 Vpp 共同索引二维查找表，以补偿元件容差、DDS 幅值响应和采样链增益误差。

## 未知模型

待测网络限定为四类二阶系统：

- 低通 LPF；
- 高通 HPF；
- 带通 BPF；
- 带阻 BSF。

辨识结果是端口等效传递函数 `type + (k, f0, Q)`。该结果描述幅频行为，不要求从端口响应唯一反推出内部 R、L、C 连接方式。

当前扫频配置为：

| 参数 | 配置 |
| --- | --- |
| 起始频率 | 100 Hz |
| 终止频率 | 200 kHz |
| 频点数 | 200 |
| 频点分布 | 对数间隔 |
| ADC 采样率上限 | 1 MS/s |
| FFT 长度 | 2048 |
| 每频点平均缓冲数 | 4 |

## 实时模拟

学习完成后，连续时间模型经双线性变换生成二阶 biquad。ADC 与 DAC 工作在同一 MCU 时钟域，默认采样率为 500 kS/s；DMA 采用 256 点循环缓冲区，每次处理 128 点。

实时路径的验收量是相同输入条件下，数字模拟输出与未知网络实际输出之间的峰峰值误差。相位连续性、过载恢复和超出模型阶数的网络不属于当前实现保证。

## 验收指标

| 项目 | 条件 | 指标 |
| --- | --- | --- |
| 已知模型控制 | 100 Hz–3 kHz，1–2 Vpp | 相对误差不超过 5% |
| 未知模型学习 | 四类二阶网络 | 输出类型、`k`、`f0`、`Q` |
| 学习时间 | 200 个扫频点 | 40 s 内 |
| 实时模拟 | 1–50 kHz 测试区间 | 幅值误差不超过 10% |
| 输出能力 | 正弦波 | 最大 4.5 Vpp |
