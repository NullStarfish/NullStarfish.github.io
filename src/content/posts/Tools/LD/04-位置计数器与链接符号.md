链接脚本中的符号没有独立存储空间。它们只是链接器符号表中的名字和值，常用于把
section 边界、栈顶和初始化范围传递给启动代码。

---

### 一、位置计数器 `.`

`.` 表示当前输出位置：

```ld
SECTIONS
{
  . = 0x80000000;

  .text : {
    *(.text .text.*)
  }
}
```

向输出段加入内容时，`.` 自动增长。可以向前移动它来留下空间：

```ld
.stack (NOLOAD) : {
  _stack_bottom = .;
  . += 16K;
  _stack_top = .;
}
```

位置计数器不能在同一个地址空间内向后移动，否则可能产生重叠错误。

---

### 二、定义边界符号

```ld
.data : {
  _data_start = .;
  *(.data .data.*)
  _data_end = .;
}
```

C 中应把这些名字声明为对象地址，而不是普通整数变量：

```c
extern char _data_start[];
extern char _data_end[];

size_t data_size = (size_t)(_data_end - _data_start);
```

汇编中可以直接取地址：

```asm
la t0, _data_start
la t1, _data_end
```

不要在 C 中写 `extern uintptr_t _data_start;` 后读取 `_data_start` 的内容；那会把该
地址处的数据当作变量值。若采用这种声明，应使用 `&_data_start` 获取符号地址。

---

### 三、对齐

```ld
. = ALIGN(16);
```

将当前位置向上对齐到 16-byte 边界。也可以直接指定输出段对齐：

```ld
.text ALIGN(16) : {
  *(.text .text.*)
}
```

常见写法：

```ld
_bss_start = ALIGN(8);
. = _bss_start;
```

`ALIGN(N)` 返回对齐后的值；只有把结果赋给 `.`，才会实际移动当前位置。

---

### 四、绝对符号与 section-relative 符号

在输出段外定义的符号通常是绝对符号：

```ld
_stack_top = ORIGIN(RAM) + LENGTH(RAM);
```

在输出段内部定义的符号通常与该 section 相关。需要强制得到绝对值时使用：

```ld
.data : {
  _data_offset = ABSOLUTE(. - ADDR(.data));
  *(.data)
}
```

最终 executable 中两者都可能显示为完整地址，但在 partial link 和 relocation 语义上
存在区别。

---

### 五、`PROVIDE` 与 `PROVIDE_HIDDEN`

```ld
PROVIDE(_stack_top = ORIGIN(RAM) + LENGTH(RAM));
```

`PROVIDE` 只在程序引用该符号且输入文件没有定义它时创建符号，因此允许程序或平台
覆盖默认值。

```ld
PROVIDE_HIDDEN(__init_array_start = .);
```

`PROVIDE_HIDDEN` 还会令 ELF 符号具有 hidden visibility。

---

### 六、断言

```ld
ASSERT(_image_end <= ORIGIN(RAM) + LENGTH(RAM),
       "RAM image does not fit")
```

表达式为 0 时链接失败并打印消息。它适合检查：

- 固件是否超过 ROM/RAM。
- 栈、堆和静态数据是否重叠。
- 向量表或页表是否满足硬件对齐。
- 某个必须存在的 section 是否为空。

---

### 七、常用内置函数

| 函数 | 含义 |
| :--- | :--- |
| `ADDR(.text)` | 输出段 `.text` 的 VMA。 |
| `LOADADDR(.data)` | 输出段 `.data` 的 LMA。 |
| `SIZEOF(.bss)` | 输出段大小。 |
| `ALIGNOF(.text)` | 输出段 alignment。 |
| `ORIGIN(RAM)` | MEMORY region 起始地址。 |
| `LENGTH(RAM)` | MEMORY region 长度。 |
| `DEFINED(symbol)` | 符号已定义时为真。 |
| `MAX(a,b)` / `MIN(a,b)` | 取最大值或最小值。 |

例如提供可覆盖的栈大小：

```ld
_stack_size = DEFINED(_stack_size) ? _stack_size : 16K;
```
