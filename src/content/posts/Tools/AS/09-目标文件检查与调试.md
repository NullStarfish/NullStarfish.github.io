汇编成功只说明源文件能被编码，不代表 section、symbol、relocation 和 ABI metadata 符合
预期。调试 GAS 输出时，应优先检查可重定位 `.o`，再检查链接后的 ELF。

---

### 一、生成 Assembly Listing

```bash
riscv64-linux-gnu-as \
  -march=rv32e -mabi=ilp32e \
  -alh=start.lst \
  -o start.o start.s
```

Listing 会把源码、地址和生成字节放在一起，适合定位 macro 展开和数据 directive。

通过 GCC driver 可以把 assembler 参数传下去：

```bash
riscv64-linux-gnu-gcc -c start.S \
  -Wa,-alh=start.lst \
  -o start.o
```

---

### 二、检查 ELF Header 与 Attribute

```bash
riscv64-linux-gnu-readelf -h start.o
riscv64-linux-gnu-readelf -A start.o
```

确认：

- ELF32/ELF64。
- little/big endian。
- machine 为 RISC-V。
- RVE、float ABI 等 ELF flags。
- `.riscv.attributes` 中的 architecture 和 stack alignment。

---

### 三、检查 Section

```bash
riscv64-linux-gnu-readelf -SW start.o
riscv64-linux-gnu-objdump -h start.o
```

确认 section 名称、type、size、alignment 和 `W/A/X` flags。链接脚本匹配失败时，先
比较这里的输入 section 名和 LD pattern。

---

### 四、检查 Symbol

```bash
riscv64-linux-gnu-readelf -sW start.o
riscv64-linux-gnu-nm -S start.o
riscv64-linux-gnu-objdump -t start.o
```

例如 `_start` 通常应显示为：

```text
GLOBAL FUNC entry ... _start
```

如果是 `LOCAL`，检查 `.globl`；如果是 `NOTYPE`，检查 `.type`；如果 size 为 0，检查
`.size`。

---

### 五、检查真实 Instruction 与 Relocation

```bash
riscv64-linux-gnu-objdump -dr start.o
riscv64-linux-gnu-objdump -dr -M no-aliases start.o
riscv64-linux-gnu-readelf -rW start.o
```

- 默认反汇编可能重新显示伪指令。
- `-M no-aliases` 更接近真实 instruction。
- `-r` 把 relocation 标在 instruction 旁边。

遇到 `la`、`call` 结果异常时，必须同时看 instruction 和 relocation，不能只看源代码。

---

### 六、比较链接前后

```bash
riscv64-linux-gnu-objdump -dr start.o
riscv64-linux-gnu-objdump -dr app.elf
```

对比可以观察：

- linker 是否应用了 relocation。
- `call` 是否被 relax。
- section 最终地址。
- symbol 是否被 GC 或合并。

---

### 七、常见错误定位

| 现象 | 优先检查 |
| :--- | :--- |
| illegal operands | `-march`、寄存器范围、immediate 范围 |
| unrecognized opcode | ISA extension 是否启用 |
| undefined reference | `readelf -s` 和 relocation，问题通常在链接阶段 |
| section 未被脚本匹配 | `readelf -S file.o` |
| `_start` 不是 global function | `.globl`、`.type`、`.size` |
| 调用地址错误 | `objdump -dr`、HI/LO relocation 配对 |
| GDB backtrace 错误 | stack frame 和 CFI 是否一致 |

### 推荐排查顺序

```text
assembler listing
  -> readelf -h -A
  -> readelf -S -s -r
  -> objdump -dr -M no-aliases
  -> 链接后再次 objdump/readelf
```
