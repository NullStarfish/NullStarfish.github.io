GAS 自己提供 macro、循环和条件汇编。这些功能在 assemble 阶段展开，不会生成运行时
branch，也不等同于 `.S` 文件先经过的 C preprocessor。

---

### 一、定义 Macro

```asm
.macro PUSH reg
  addi sp, sp, -4
  sw \reg, 0(sp)
.endm

PUSH ra
PUSH s0
```

Macro 参数通过 `\name` 引用。支持默认值和必填参数：

```asm
.macro SAVE reg:req, offset=0
  sw \reg, \offset(sp)
.endm

SAVE ra, 12
```

`:req` 表示参数不能为空，`:vararg` 表示接收剩余参数。

---

### 二、避免参数与文本粘连

如果参数后紧接普通字符，使用 `\()` 分隔：

```asm
.macro MAKE_LABEL name
\name\()_entry:
.endm
```

否则 assembler 可能把 `\name_entry` 当作另一个参数名。

每次 macro 展开都有唯一计数器 `\@`：

```asm
.macro WAIT_ZERO reg
.Lwait_\@:
  bnez \reg, .Lwait_\@
.endm
```

这样多次调用不会产生重复 label。

---

### 三、重复展开

固定次数重复：

```asm
.rept 4
  nop
.endr
```

遍历参数列表：

```asm
.irp reg, ra, s0, s1
  PUSH \reg
.endr
```

逐字符遍历字符串：

```asm
.irpc digit, 1234
  .byte \digit
.endr
```

`.rept`、`.irp` 和 `.irpc` 都是在 assemble 阶段生成重复文本或数据。

### 四、条件汇编

```asm
.if XLEN == 32
  .word 0
.elseif XLEN == 64
  .dword 0
.else
  .error "unsupported XLEN"
.endif
```

`.if` 的参数必须是 assembler 能立即求值的 absolute expression。

常见变体：

```asm
.ifdef SYMBOL
.ifndef SYMBOL
.ifc "string1", "string2"
.ifnc "string1", "string2"
.ifb text
.ifnb text
```

- `.ifdef` 检查 GAS symbol 是否已定义。
- `.ifc` / `.ifnc` 比较字符串是否相同。
- `.ifb` / `.ifnb` 检查参数是否为空。

---

### 五、Assembler 诊断

```asm
.warning "deprecated path"
.error "invalid configuration"
.abort
```

可以在 macro 中检查参数：

```asm
.macro ALLOC_FRAME size:req
  .if (\size) % 16
    .error "stack frame must be 16-byte aligned"
  .endif
  addi sp, sp, -(\size)
.endm
```

### 六、GAS Macro 与 CPP Macro

`.S` 文件中的 CPP：

```asm
#define UART_BASE 0x10000000
#ifdef CONFIG_UART
  li a0, UART_BASE
#endif
```

GAS 自身：

```asm
.equ UART_BASE, 0x10000000
.ifdef UART_BASE
  li a0, UART_BASE
.endif
```

两者的主要区别：

| 特性 | CPP | GAS |
| :--- | :--- | :--- |
| 执行阶段 | assembler 之前 | assembler 内部 |
| 文件后缀 | 通常要求 `.S` | `.s`、`.S` 都可 |
| 参数宏 | `#define` | `.macro` / `.endm` |
| 条件 | `#if` / `#ifdef` | `.if` / `.ifdef` |
| 是否理解 assembler symbol | 否 | 是 |

不要让同一个名字同时承担 CPP macro 和 GAS symbol，排查展开结果会很痛苦。
