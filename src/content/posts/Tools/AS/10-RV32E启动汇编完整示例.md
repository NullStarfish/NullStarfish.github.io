下面的示例展示典型裸机 `_start`。它与收集 `*(entry)` 的链接脚本配合，初始化 `gp`、
`sp`、`.data` 和 `.bss`，最后调用 C 入口 `_trm_init`。

具体初始化职责取决于 loader：如果 loader 已经按 ELF segment 放置 `.data` 并清零
`.bss`，对应循环可以省略。

---

### 一、完整启动文件

```asm
.section entry, "ax", @progbits
.globl _start
.type _start, @function
.option nopic

_start:
  /* Establish a known frame-pointer value. */
  mv s0, zero

  /* Initialize gp without allowing GP-relative relaxation. */
  .option push
  .option norelax
  la gp, __global_pointer$
  .option pop

  /* The linker script provides the initial stack address. */
  la sp, _stack_pointer

  /* Copy initialized data from LMA to VMA. */
  la a0, _data_load_start
  la a1, _data_start
  la a2, _data_end
.Lcopy_data:
  beq a1, a2, .Lclear_bss
  lbu t0, 0(a0)
  sb t0, 0(a1)
  addi a0, a0, 1
  addi a1, a1, 1
  j .Lcopy_data

  /* Clear zero-initialized storage. */
.Lclear_bss:
  la a0, _bss_start
  la a1, _bss_end
.Lclear_bss_loop:
  beq a0, a1, .Lcall_runtime
  sb zero, 0(a0)
  addi a0, a0, 1
  j .Lclear_bss_loop

.Lcall_runtime:
  call _trm_init

  /* _trm_init should not return. */
.Lhang:
  j .Lhang

.size _start, . - _start
```

RV32E 只有 `x0` 到 `x15`，因此示例只使用 `s0`、`gp`、`sp`、`t0`、`a0-a2` 等 RVE
可用寄存器，没有使用 `t3`、`a6` 等高编号寄存器。

### 二、对应链接脚本接口

```ld
ENTRY(_start)

SECTIONS
{
  .text : {
    KEEP(*(entry))
    *(.text .text.*)
  }

  .data : {
    _data_start = .;
    PROVIDE(__global_pointer$ = . + 0x800);
    *(.sdata .sdata.*)
    *(.data .data.*)
    _data_end = .;
  } > RAM AT> FLASH

  _data_load_start = LOADADDR(.data);

  .bss (NOLOAD) : {
    _bss_start = .;
    *(.bss .bss.*)
    *(COMMON)
    _bss_end = .;
  } > RAM

  _stack_pointer = ORIGIN(RAM) + LENGTH(RAM);
}
```

Assembler 与 linker script 之间通过这些名字形成接口：

| 汇编引用 | Linker 提供 |
| :--- | :--- |
| `_stack_pointer` | 初始栈顶地址 |
| `_data_load_start` | `.data` 的 LMA |
| `_data_start/_data_end` | `.data` 的 VMA 范围 |
| `_bss_start/_bss_end` | `.bss` 清零范围 |
| `__global_pointer$` | 脚本在 small-data 附近提供的 GP anchor |

---

### 三、为什么 `entry` 需要 `KEEP`

Assembler 生成名为 `entry` 的输入 section：

```asm
.section entry, "ax", @progbits
```

Linker script 必须匹配同名 section：

```ld
KEEP(*(entry))
```

使用 `--gc-sections` 时，`KEEP` 能明确保留启动 section。`ENTRY(_start)` 通常也会让
入口所在 section 成为 GC root，但同时使用 `KEEP` 能更直接表达硬件启动约束。

### 四、编译和检查

```bash
riscv64-linux-gnu-gcc \
  -march=rv32e -mabi=ilp32e \
  -fno-pic -fno-pie \
  -g -c start.S -o start.o

riscv64-linux-gnu-readelf -SW -sW -rW -A start.o
riscv64-linux-gnu-objdump -dr -M no-aliases start.o
```

确认：

- `entry` 是 `AX` 的 `PROGBITS` section。
- `_start` 是 `GLOBAL FUNC`，size 非零。
- `la` 和 `call` 生成合理的 RISC-V relocation。
- ELF attribute 显示 RVE/ILP32E 配置。

链接后再检查最终地址和 relaxation：

```bash
riscv64-linux-gnu-objdump -dr app.elf
riscv64-linux-gnu-readelf -h -l app.elf
```
